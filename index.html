Image Hosting — ImgBB

Currently not active — every image lives only in this browser's local storage. Add an ImgBB API key to optionally back up occlusion images to the cloud as you add them.

⚠ This is a static, no-backend build, so there's no server to keep the key private — it's used directly from your browser and is visible in outgoing network requests. Fine for a personal key on a personal deployment; don't use a shared/team key here. A serverless relay (the more secure option, same pattern Kardex uses) is a separate build if you want it.
